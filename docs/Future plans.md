## Upcoming improvements

We will also work on the next major release, which will include new features:

i. Create a mechanism to integrate external data sources such as Empatica EmbracePlus

ii. Amazon S3 and RDS storage integration

iii. A visualisation module which can offer custom visualisations

iv. Create consistent column names based on the schema, regardless of source format.

v. Functionality to create parameterised features that could be changed from the config

vi. Custom feature to create windowed data aggregation.

vii. Support for relative time sampling, i.e, the first 10 days from recruitment.
